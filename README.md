# FORMA CLI website

The standalone product landing page for [FORMA CLI](https://github.com/EgoisticCoder/Forma_CLI), a visual coding agent with an isolated, permissioned Playwright browser and screenshot-based UI/UX audits.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build`, then serve it with `npm start`. The site is a Next.js app and can be deployed to Vercel or another Node.js-compatible host.
